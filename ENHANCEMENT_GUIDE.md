### 4. **Investment Growth Calculator**

#### Features:
- **Adjustable Parameters**:
  - Monthly contribution (R300-R2000)
  - Investment period (1-10 years)
  - Expected return rate (6-12%)
- **Real-Time Calculations**: Instant updates as sliders move
- **Visual Projections**: Interactive chart showing growth over time
- **Comparison Display**: Shows contributions vs returns

#### Formula Used:
```python
Future Value = Monthly Payment × (((1 + r)^n - 1) / r)
Where:
  r = monthly interest rate (annual rate / 12)
  n = number of months
```
