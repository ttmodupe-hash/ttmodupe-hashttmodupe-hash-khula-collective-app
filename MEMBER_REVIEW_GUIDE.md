## 🐛 How to Report Bugs

When reporting bugs, please include:

1. **What you were trying to do**
2. **What happened instead**
3. **Steps to reproduce the issue**
4. **Screenshots (if possible)**
5. **Device/browser you're using**

**Example:**
```
BUG REPORT:
- Trying to: View my contribution history
- What happened: Page showed error message
- Steps: Login → Dashboard → Click "View History"
- Screenshot: [Attached]
- Device: iPhone 12, Safari browser
```

---

## 💡 Feature Request Guidelines

We welcome all suggestions! When requesting features:

1. **Describe the feature clearly**
2. **Explain why it would be useful**
3. **Suggest how it might work**
4. **Indicate priority (Nice to have / Important / Critical)**

**Example:**
```
FEATURE REQUEST:
- Feature: Export my contribution history to PDF
- Why useful: For personal record keeping and tax purposes
- How it works: Add "Download PDF" button on dashboard
- Priority: Nice to have
```
