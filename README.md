# 🇿🇦 Khula Collective - Investment Club Platform

A mobile-first, FICA-compliant investment club platform for 20 members pooling R300/month into a collective pot.

## 🚀 Quick Deploy to Streamlit Cloud

[![Deploy to Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/)

### 3-Step Deployment:

1. **Go to:** https://share.streamlit.io/
2. **Click:** "New app"
3. **Enter:**
   - Repository: `ttmodupe-hash/ttmodupe-hashttmodupe-hash-khula-collective-app`
   - Branch: `main`
   - Main file: `app.py`
   - URL: `khula-collective` (your choice)

**Done!** You'll get a permanent URL like: `https://khula-collective.streamlit.app/`

📖 **Full deployment guide:** [STREAMLIT_CLOUD_SETUP.md](STREAMLIT_CLOUD_SETUP.md)

## 📱 Features

### Mobile-First Design
- ✅ Touch-friendly buttons (50px+ height)
- ✅ Responsive layouts that stack vertically
- ✅ Optimized for smartphones

### Digital Constitution
- ✅ Full constitution text in sidebar
- ✅ Digital signature with timestamp
- ✅ FICA-compliant storage
- ✅ Required before voting

- ✅ Payment history calendar (✅/❌)
