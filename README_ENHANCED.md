## 🚀 Quick Start

### 1. Run Locally:
```bash
# Install dependencies
pip install -r requirements_final.txt

# Run enhanced version
streamlit run khula_enhanced.py

# Access at http://localhost:8501
```

### 2. Deploy to Streamlit Cloud:
1. Push to GitHub
2. Connect to Streamlit Cloud
3. Select `khula_enhanced.py` as main file
4. Deploy!

### 3. Explore Features:
1. Visit landing page
2. Click "Explore Demo" (no login needed)
3. Try investment calculator
4. View comparison charts
5. Register or login to see full features
