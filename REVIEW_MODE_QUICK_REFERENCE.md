# 🔍 Review Mode - Quick Reference Card

## 🎯 What is Review Mode?

A **safe testing environment** that uses mock data instead of real bank credentials. Perfect for member onboarding and training.

---

## 🚀 Quick Start (Admin)

### Enable Review Mode:
1. Login as `admin_khula` / `admin123`
2. Look for **"🔍 Review Mode"** in sidebar
3. Toggle **ON** "Enable Review Mode"
4. Orange banner appears: "🔍 REVIEW MODE ACTIVE"
5. Share app URL with members

### Disable Review Mode:
1. Toggle **OFF** "Enable Review Mode"
2. Banner disappears
3. Real bank data loads
